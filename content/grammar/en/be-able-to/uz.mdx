## Asosiy g'oya

**can** ning shakllari kam: *can / could*. Qolgan hamma joyda **be able to** yordam beradi.

| Zamon | Shakl |
|---|---|
| Hozirgi | can / am able to |
| O'tgan | could / was able to |
| Kelasi | will be able to |
| Present Perfect | have been able to |
| -ing / to | being able to / to be able to |
